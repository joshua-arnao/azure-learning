# MICROSOFT ENTRA DOMAIN SERVICES
Es un servicio en la nube que ofrece un dominio de Active Directory totalmente administrado con funciones tradicionales como unión a dominios, LDAP y Kerberos

Complemente las funciones que tiene Microsoft Entra ID

> LDAP: Protocolo ligero de acceso a direccitorios, es el protocolo estándar que **permite a las aplicaciones antiguas o heredadas buscar información de usuarios, grupos y autenticarse** contra el directorio de la

Dominio administrado da el soporte para LDAP
