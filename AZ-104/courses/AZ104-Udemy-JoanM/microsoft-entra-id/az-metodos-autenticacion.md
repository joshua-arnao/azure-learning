# Métodos de autenticación de Azure


## Solo Password
Es categorizado como **Bad** ya que tendras problemas como fishing, ya que al no tener una segunda barrera de protección entraran

## Password y un segundo factor
Es categorizado como **Good** ya que se tiene un 2MFA un segundo factor de seguridad recibiendo mensajes de texto o voz adicional a la contraseña

## Password y --
Es categorizado como **Better** adicional a la contraseña se usara tambien Software de autenticación para un push notification, Token de software o Token Hardware 

## Passwordless
Es categorizada como **Best** ya que no se necesita una contraseña ya que usa un Software de autenticación pero Phone Sign-In, tambien s epuede usar Window Hello para que el usaurio incie con un Pin, reconocimeinto facil o un pin o usa un FIDO2 security key o tambien alguna certificación
