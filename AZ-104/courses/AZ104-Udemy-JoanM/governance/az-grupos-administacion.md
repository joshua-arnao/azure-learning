# GRUPOS ADMINISTRACIÓN - MANAGMENT GROUPS
Es un **estrucutra jerárquica** que permite **organizar** y **adminsitrar** múltiples suscripciones de Azure

## Características
- Organiza suscripciones en una estrucutra jerárquica
- Aplica políticas e inciativas consistentemente a todas las suscripciones dentro de un grupo.
- Establece roles y permisos a nivel de grupo para adminsitrar el acceso a las suscripciones y recursos de manera unificada

## Casos de uso:
- Diferentes departamentos en una organización
- Distintos entornos (prod, dev, test)
