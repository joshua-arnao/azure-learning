# FACTURACIÓN DE GITHUB

---
## FACTURACIÓN EN GITHUB
GitHub factura cuentas basadas según su tipo, ya sea: *personal*, *organización* o *empresa*.

Las cuentas *personales* y la mayoría de las *organizaciones* **reciben facturas independientes**.

Las cuentas *empresariales* pueden **consolidar la facturación en varias organizaciones** o **enrutar los cargos a diferentes centros de costos** en función de la configuración interna.

Cada factura puede reflejar una combinación de **cargos de licencia basados en suscripciones** y **cargos basados en el uso**:

- **Los cargos de suscripción y licencia** se aplican a productos y servicios asignados a una cuenta, como *GitHub Pro*, *GitHub Team* o puestos de *GitHub Copilot*. 
- **La facturación basada en el uso** se aplica a los productos en los que los costos se pueden escalar con el consumo, como *Acciones de GitHub*, *paquetes de GitHub* y *características de GitHub Copilot admitidas*.

## FACTURACIÓN GITHUB COPILOT
GitHub Copilot usa una combinación de **facturación basada en licencias** y **facturación basada en el uso**.

Las organizaciones y las empresas se facturan por las licencias de GitHub Copilot asignadas a los usuarios. Se pueden agregar más puestos Copilot durante un ciclo de facturación y se prorratean durante el período en el que se asignan. La eliminación de un puesto generalmente afecta a la facturación en el siguiente ciclo de facturación.

Una licencia de Copilot asignada no debe tratarse como equivalente a un usuario activo. Un usuario puede tener asignada una licencia de Copilot facturable aunque no haya usado recientemente Copilot.
