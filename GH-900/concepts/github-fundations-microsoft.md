

## GITHUB PLATAFORMA COLABORATIVA
### ISSUES
Los **ISSUES** se usan para realizar seguimiento de ideas, comentarios, tareas o erores para trabajar en GitHub. 

#### CREACIÓN DE UN ISSUE DESDE UN REPOSITORIO
1. Ir a la página principal del repositorio.
2. En el nombre del repositorio, seleccione Problemas.
3. Seleccionar nueva incidencia.
4. En el campo **Agregar un título**, escribir título del problema.
5. En el campo  **Agregar una descripción**, escribir una descripción del problema.
6. Un **project maintainer**, puede asignar la incidencia a alguien, agregarla a un panel de proyecto, asociarla a un hito o aplicar una etiqueta.
