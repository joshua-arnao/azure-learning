# GITHUB PLATAFORMA COLABORATIVA
## ISSUES
Se usan para realizarun seguimiento de ideas, comentarios, tareas o errores para trabajar en GitHub.

Las **Issues** se pueden crear a partir de:
- Un Repositorio
- Una nota de un proyecto
- Un comentario en una incidencia o una solicitud de incorporación de cambios.
- Una línea de código especifica.
- Una consulta de la dirección URL.

## CREACIÓN DE UN ISSUE DESDE UN REPOSITORIO
1. En [GitHub](https://github.com), ir a la página principal del repositorio.
2. En el nombre del repositorio, seleccionar **Issues**
3. Seleccionar **New Issue**. Debería abrir un campo de incidencia en blanco para rellenarlo.
4. Si el repositorio usa plantillas de issue, debe obtener una lista de tipos de issues, seleccione la que desea usar. 
Si el tipo de issue que desea abrir no se incluye en las opciones disponibles, seleccione **Issue en blanco**. Si no usa plantillas, vaya al paso 5.
5. En el campo **Agregar un título**, escribir un título para el issue.
6. En el campo **Agregar una descripción** , escribir una descripción del issue.
7. Al finalizar, seleccionar **Create**

Usar etiquetas, menciones y reacciones para administrar la colaboración de forma eficaz y aumentar las visibilidad de los issues.
