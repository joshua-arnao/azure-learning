# BRANCH
Son versiones independientes del código de un proyecto. Permiten trabajar en nuevas características o correcciones sin afectar la rama principal, facilitando el desarrollo colaborativo y la implementación de nuevas funcionalidades.

## CREACIÓN Y GESTIÓN DE BRANCHS EN GITHUB
Permite trabajar en nuevas funcionalidades o correcciones sin afectar la rama principal, facilitando la organización y revisión del código.

## FORK
Es la creación de una copia independiente de un repositorio ajeno. Permite a los usuarios contribuir a una proyecto sin afectar el repositorio original y ofrece flexibilidad para experimentar y proponer cambios.

## PULL REQUESTS Y COLABORACIÓN
Son propuestas de cambios que permite a los colaboradores discutir, revisar y fusionar contribuciones al repositorio principal. Facilitan la colaboración y la integración de nuevas funcionalidades de manera estructurada.
